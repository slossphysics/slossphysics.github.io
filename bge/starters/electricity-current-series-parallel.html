Current in series and parallel

LI: I am learning how current behaves in series and parallel circuits.

SC: I can use one ammeter reading to find another in a series circuit · I can add branch currents in a parallel circuit · I can explain why current is not used up.

5:00

1.Match each word to its meaning.

Drag each word onto its meaning, or tap a word and then its meaning.

Current is the flow of charge. It is measured in amperes (A) with an ammeter. At a junction the current can split.

2.Ammeter P reads 0.40 A. What does ammeter Q read?

A

Current isn’t shared out between the lamps in a series circuit. Is there anywhere else for it to go?

If no current reached Q, none could flow through the lamps either: it’s all one loop.

Current doesn’t build up as it goes round a single loop.

A series circuit has only one path, so the current is the same everywhere: Q reads 0.40 A.

3.Two identical lamps are in series with a cell. A third identical lamp is added to the same loop. What happens to the current?

Hint

Think back to your experiment: when you added more lamps in series, did they get brighter or dimmer?

Each lamp makes it harder for current to flow round the one loop, so adding a lamp makes the current smaller everywhere in the circuit, and all the lamps dimmer.

4.Spot the mistake. Sam says: “Current leaves the cell and goes through lamp X first. X uses up some of the current, so less reaches lamp Y.” What is wrong?

The current is the same all the way round a series circuit. Lamps transfer energy; they don’t use up current.

5.Sort each statement into series or parallel.

Drag each card into its group, or tap a card and then the group.

Series: one path, so the current is the same everywhere. Parallel: the current splits into branches, and the branch currents add up to the current from the cell.

6.Which ammeter measures the current through lamp Y only?

Hint

For each ammeter, ask: does current for lamp X flow through it, current for lamp Y, or both?

R is in series with lamp Y on Y’s own branch, so only the current through Y flows through it.

7.The lamps are identical. Ammeters X and Y each read 0.30 A. What does ammeter Z read?

A

That’s the current in one branch. Z carries the current for both branches.

The current isn’t halved again. At the dots the two branch currents join back together.

The branch currents add up to the current from the cell: 0.30 A + 0.30 A = 0.60 A.

8.The two lamps are different. Ammeter Z reads 0.50 A and ammeter X reads 0.20 A. What does ammeter Y read?

A

The branch currents add up to Z’s reading, so Y must be less than Z.

The lamps are different, so the current doesn’t split equally. Use Z’s and X’s readings.

Z carries the current for both branches. Y only carries its own branch’s share.

Hint

The current from the cell (Z) splits into the two branches (X and Y). What must X and Y add up to?

X + Y = Z, so 0.20 A + Y = 0.50 A. That means Y = 0.50 A − 0.20 A = 0.30 A.

Challenge9.The two lamps are identical and ammeter Z reads 0.80 A. A third identical lamp is added on a new branch, in parallel with the other two. What does Z read now?

A

The new branch is a new path for current. Does the cell now supply more current, or the same?

The new lamp doesn’t take a share of the old current. Each identical branch carries the same current as before.

That’s the current in one branch. How many branches are there now?

Hint

First work out the current in each branch now. Adding a branch doesn’t change the current in the branches already there.

Each identical branch carries 0.80 A ÷ 2 = 0.40 A. With three branches, Z = 3 × 0.40 A = 1.2 A. Each new branch adds its own current.
