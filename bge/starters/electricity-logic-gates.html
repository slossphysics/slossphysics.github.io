Logic gates

LI: I am learning how logic gates make decisions in electronic systems.

SC: I can recognise AND, OR and NOT gates · I can complete a truth table · I can choose a gate for a real situation.

5:00

1.Match each logic gate symbol to its name.

Drag each symbol onto its name, or tap a symbol and then its name.

AND has a flat back and a round front. OR has a curved back and a pointed front. NOT is a triangle with a small circle, and has only one input.

2.In a logic circuit, what does 1 stand for?

Logic gates only use two states: 1 = high (on) and 0 = low (off).

3.An AND gate has input A = 1 and input B = 0. What is the output?

Hint

Say it as a sentence: "The output is 1 if A is 1 AND B is 1." Is that true here?

An AND gate only gives 1 when both inputs are 1. Here B is 0, so the output is 0.

Look at the last row carefully. Does "A is 1 OR B is 1" stay true when both of them are 1?

The output of an OR gate is 1 when A or B is 1, including when both are. It is only 0 when both inputs are 0.

7.Match each situation to the logic gate it needs.

Drag each situation onto a gate, or tap a situation and then a gate.

Listen for the key word: both things needed is AND, either thing is enough is OR, and the opposite of the input is NOT.

8.A greenhouse temperature sensor gives 1 when it is warm and 0 when it is cold. The heater should come on (1) when it is cold. Which gate should go between the sensor and the heater?

Hint

Write down the output you want when the sensor gives 0, and when it gives 1. How does the output compare with the input?

When the sensor gives 0 (cold), the heater needs 1. The output is always the opposite of the input, so it needs a NOT gate.
