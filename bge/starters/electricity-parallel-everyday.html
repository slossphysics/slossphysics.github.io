BGE · Third level · Forces, electricity and waves · SCN 3-09a

Parallel circuits in everyday life

LI: I am learning why parallel circuits are used in everyday life.

SC: I can explain the advantages of parallel circuits · I can choose where to put switches in a circuit · I can add up the currents in a house circuit.

5:00

1.In an old set of fairy lights, when one bulb breaks they all go out. How are the bulbs connected?

The bulbs are in series: one broken bulb leaves a gap in the only loop, so no current flows anywhere.

2.The lights in a house are wired in parallel. Tap all 3 advantages of this.

Each light is on its own branch: it has its own switch, keeps working if another breaks, and gets the full voltage.

3.Sort these into usually series or usually parallel.

Drag each card into its group, or tap a card and then the group.

Hint

For each pair, ask: should one keep working when the other is switched off or broken? Or must they always work together, in the same loop?

Things that must work independently are in parallel. A switch must be in series with the light it controls, so it can break that light’s loop.

4.Every socket in a house gets the full 230 V mains voltage. Why?

The sockets are in parallel. Each branch is joined straight across the supply, so each socket gets the full 230 V.

5.Switch S is open, as shown. Which lamps are lit?

Hint

For each lamp, try to trace a complete loop from the cell, through that lamp, and back to the cell.

The open switch breaks lamp X’s branch only. Lamp Y still has a complete loop with the cell, so it stays lit.

6.Which one switch turns both lamps off?

P is next to the cell, so the current for both branches flows through it. Opening P breaks every loop.

7.Which circuit lets each lamp be switched on and off by itself?

Hint

For each circuit, imagine opening one switch. Does it break the loop for one lamp, or for both?

Each lamp is on its own branch with its own switch, so opening one switch only breaks that lamp’s loop.

8.The sockets in a kitchen are wired in parallel. A kettle takes a current of 9.0 A and a toaster takes 4.0 A. Both are switched on. What is the total current from the supply?

A

The currents in parallel branches add up; they don’t take away.

That’s the kettle on its own. The supply provides the current for both branches.

The branches don’t share one current: each takes its own, and they add up.

The branch currents add up: 9.0 A + 4.0 A = 13 A. This is why plugging too much into one socket is dangerous: the total current can get too big.

Challenge9.A model house needs two lamps that can each be switched on and off by themselves, plus one main switch that turns everything off. Which circuit does both jobs?

Hint

Check each circuit for both jobs: is there a switch that only one lamp’s current flows through, and one that all the current flows through?

A switch on each branch controls that lamp by itself. A main switch next to the cell carries all the current, so opening it turns everything off.
