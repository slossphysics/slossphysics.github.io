Ready for current in parallel

LI: I am recalling what I know about circuits, ready to measure current in a parallel circuit.

SC: I can name circuit symbols · I can tell a series circuit from a parallel circuit · I can say what adding cells or lamps does to the current · I can use the rule for current in a series circuit.

5:00

1.Match each symbol to its name.

Drag each symbol onto its name, or tap a symbol and then its name.

Hint

A cell has one long line and one short, thick line. A battery is more than one cell joined together, so look for more lines.

The ammeter is the circle with an A: it measures current in amps. A battery is two or more cells joined together.

2.Is this circuit series or parallel?

Hint

Follow the wire from the cell. One path with no splits means series. If the wire splits at a junction (a dot), there are branches.

At the dot the current can go two ways, so there is more than one path. Each lamp is on its own branch: this is a parallel circuit.

3.Both lamps are lit. Lamp X is then unscrewed. What happens to lamp Y?

Hint

Think back to the circuit you built where one bulb “piggybacked” the other. What happened when you unscrewed one?

In a parallel circuit each lamp has its own path to the cell. Unscrewing X only breaks X’s branch, so lamp Y stays lit.

If we add more lamps to a series circuit, the current and the lamps get .

More cells give a bigger push, so the current increases. More lamps in the same loop make it harder for the current to get round, so the current decreases and the lamps are dimmer.

5.Ammeter A1 reads 0.25 A. What does ammeter A2 read?

A

The current isn’t shared out between the lamps. Lamps don’t use up current: is there anywhere else for it to go?

Current doesn’t build up as it goes round a single loop. Is there anywhere for extra current to come from?

If no current reached A2, none could flow through the lamps either: it’s all one loop.

Hint

Last lesson you moved the ammeter to three different positions in a series circuit. What did you notice about the three readings?

In a series circuit the current is the same at all points, so A2 also reads 0.25 A.
