Current, voltage and resistance

LI: I am learning how current, voltage and resistance are linked.

SC: I can give the unit of each quantity · I can measure current and voltage for a resistor · I can describe the graph for a fixed resistor.

5:00

1.Match each unit to the quantity it measures.

Drag each unit onto its quantity, or tap a unit and then its quantity.

Current is measured in amperes (A), voltage in volts (V) and resistance in ohms (Ω).

2.What does the resistance of a component tell you?

Resistance is how much a component opposes the current. The bigger the resistance, the smaller the current for the same voltage.

3.Which circuit correctly measures the current through the resistor and the voltage across it?

Hint

Current has to flow through an ammeter. A voltmeter compares the two sides of a component.

The ammeter goes in series (in the loop). The voltmeter goes in parallel (across the resistor).

4.The voltage across a fixed resistor is increased. What happens to the current through it?

A bigger voltage pushes a bigger current through the same resistor.

5.Which graph shows voltage against current for a fixed resistor?

Hint

Two things to check: what is the current when the voltage is zero, and does doubling the voltage double the current?

For a fixed resistor the graph is a straight line through the origin: double the voltage and the current doubles.

0.4 A. Each time the voltage goes up by 2 V, the current goes up by 0.1 A. The current is always the voltage divided by 20.

7.Resistors P and Q are each connected to a 6 V supply. The current through P is 0.2 A. The current through Q is 0.6 A. Which has the bigger resistance?

Hint

Both have the same push (6 V). A bigger resistance makes it harder for current to get through. Which one lets less current through?

With the same voltage, the resistor with the smaller current has the bigger resistance. P only lets 0.2 A through.

  • R = V / I
  • R = 3 / 0.1
  • R = 30 Ω

Challenge9.The graph shows results for two fixed resistors, A and B. Which has the bigger resistance?

Hint

Pick one value of current on the I axis and go straight up. Which resistor needs the bigger voltage to push that current through it?

For the same current, A needs a bigger voltage, so A has the bigger resistance (R = V / I). On a V against I graph, the steeper line has the bigger resistance.
